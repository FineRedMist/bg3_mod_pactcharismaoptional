# Pact Weapons Charisma Optional

Provides a toggle for pact and hexblade bound weapons to use charisma.

Note: There is a known issue where the character portrait does not show the right values, but the tooltip does.

I tried really hard to get this to work in the BG3 toolkit, but I couldn't get PactOfTheBlade to also grant the status PACT_BLADE_CHARISMA when it was taken as an invocation. This adds a tick check for it.

It also removes the inventory bound attribute to pact weapons. This allows throwing.
